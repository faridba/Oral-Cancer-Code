The following packages need to be installed:
- pandas, numpy, scikit-learn, xgboost, imabalanced-learn,
- For mrmr: https://github.com/smazzanti/mrmr

The data is available under the name: qV2 HNSCC Tissue Cohorts (all).xlsx

For the code:
- For nested k fold cross validation: python kfold cv.py
- For intra data analysis among different cohorts: python intra data validation.py
